# Sales Analysis Project

This project is a data analysis project based on a retail sales dataset.

The main goal of the project is to clean the data, explore different aspects of the sales, and find useful patterns and insights from it.

## What I worked on

- Data cleaning and handling missing values
- Checking duplicate and incorrect records
- Data type conversion
- Checking unusual values and outliers
- Exploratory Data Analysis (EDA)
- Sales and profit analysis
- Customer and gender analysis
- Age group analysis
- Region and city analysis
- Product and product category analysis
- Payment method analysis
- Customer satisfaction and returns
- Shipping time analysis

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset

The dataset contains retail order information such as:

- Order details
- Customer information
- Product and category
- Sales and profit
- Discounts
- Payment method
- Customer satisfaction
- Returns
- Shipping time

## Some Findings

- Male, Female and Other customers are almost equally distributed.
- Male and Other customers generated more sales than Female customers.
- Male customers generated the highest profit.
- South region generated the highest sales and profit.
- Central region generated the lowest sales and profit.
- The 30–40 age group generated the highest sales and profit.
- Age 35 generated the highest sales and profit.
- Chennai generated the highest profit.
- Electronics generated the highest profit among product categories.
- Desk generated the highest profit among products.
- UPI was the most commonly used payment method.
- Groceries had the lowest customer satisfaction.
- Electronics had the highest number of returns.
- Most orders took 8 days to ship.
